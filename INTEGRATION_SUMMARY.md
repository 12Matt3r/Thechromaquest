## 🎮 How It Works in Practice

### **During Gameplay**
1. Player encounters surreal scene (e.g., "Baby Dolphins Swimming Through Clock Radio")
2. System auto-detects anomaly keywords and logs it (40% chance)
3. Other players may later encounter similar baby dolphin themes
4. Anomaly influence grows stronger with each encounter

### **Player Injection**
1. Player sees something they want to share (e.g., baby dolphins)
2. Clicks "📋 Log Anomaly" button
3. Uploads image (optional) and writes description
4. Creates persistent anomaly for other players to discover

### **Dream Integration**
1. Player types command: "Touch the rippling time-stream"
2. System checks for relevant anomalies
3. Finds baby dolphin anomaly, adds context
4. Narrative becomes: "You feel baby dolphins swimming through the time-stream"
