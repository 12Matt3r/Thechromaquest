Title: ChrømaShift: The Psychedelic Quest for the Chroma Award

1. Project Overview & Concept

ChrømaShift is an Anti-Linear, Open-Agency Urban Dream Simulator that traps the player within a hostile, hyper-surreal consciousness stream. It is not a game about winning or losing; it is an immersive, psychedelic quest where the player's goal is to successfully navigate a fragmented reality to claim the Chroma Award, the validation of their lost identity.

  • Setting: The quest begins in a distorted version of the player's own living room, using a glitching CRT Television as the portal to the dreamscape.
  • Narrative Core: The player must collect abstract resources called Chroma-Keys (paradoxes, impossible colors, memory fragments) by making non-linear choices that drive the hidden storyline forward.
  • Aesthetic: Hyper-Realism meets Surrealism, using 8K photorealistic panoramas filtered through dream logic—melting objects, non-Euclidean geometry, and a high-brightness, psychedelic color palette (Neon Pink, Liquid Mercury).

2. Core Game Mechanics & Innovation

  • Multimodal, Dynamic Rendering: Every player choice triggers a compulsory 4-step multimodal sequence:
    1. Narrative Generation – AI generates the plot beat and dialogue.
    2. Image Generation – AI generates a new 360° panoramic image based on the narrative text.
    3. Audio (TTS) Playback – Text-to-Speech reads only the narrative description over the transition.
    4. Dynamic UI Placement – Semi-transparent choice bubbles are dynamically mapped to contextually relevant visual points within the 360° scene, forcing interactive exploration.
  • Immersive Transition: Scene transitions use a Critical Transition Sequence with a full-screen CRT glitch effect, layered with the Eye Blink Mechanism and Reality Flash flicker.
  • Dynamic State: Player stats (Lucidity, Reality Coherence, Perception) fluctuate constantly based on choices, reflecting the unstable nature of the dream.

3. Advanced Prompt Engineering & AI Tooling

  • Platform Used: Built and refined using Websim, an AI-powered platform that transforms text prompts into dynamic web applications and games.
  • Reasoning Framework: Narrative is managed using a ReAct logic approach (Reasoning and Acting), letting the AI determine the next plot point, generate the scene, and observe results for continuity.
  • Storyline Control: Governed by the Psychedelic Chroma Award Quest Master Prompt, enforcing explicit chaining and maintaining the plot arc.
  • Player Engagement: Contextual priming injects an immediate conflict at the start of the game, compelling the player to act instantly.

# 🌀 ChromaShift: Hyper-Surreal Dreamscape

**An Anti-Linear, Open-Agency Urban Dream Simulator**

---

## 🎨 CONCEPT OVERVIEW

**ChromaShift** is a hyper-surreal dreamscape experience (melting objects, impossible physics) that traps the player in a "Chroma-Dream"—a reality-bending state where the laws of physics and logic are advisory at best. Unlike traditional narrative-driven games, ChromaShift offers **total player agency** with no fixed objectives, only exploration and reaction to an increasingly distorted consciousness.

### Core Design Pillars

1. **Hyper-Realism Meets Surrealism**: Recognizable modern environments (supermarkets, streets, buildings) filtered through dream logic and impossible geometry
2. **Total Player Agency**: No predetermined narrative arc—only wildly non-linear choices that encourage chaotic exploration
3. **Surrealist Aesthetic**: Melting objects, elongated limbs, non-Euclidean geometry, and high-brightness 8K visual quality
4. **WTF Moments**: Every scene contains shocking, absurdist elements that challenge perception
5. **Consciousness-Based Gameplay**: Your actions alter the fabric of the subconscious dream world

---

## 🎮 GAME MECHANICS

### The Chroma-Dream State

You are trapped in a hyper-vivid consciousness stream where:
- **Reality Coherence** fluctuates based on your choices
- **Lucidity** determines your awareness within the dream
- **Perception** shifts between different states of awareness
- **Temporal Logic** is completely shattered

### Core Stats

| Stat | Description | Effect |
|------|-------------|--------|
| **LUCIDITY** | Your awareness level within the dream | Higher = more control over dream navigation |
| **REALITY COHERENCE** | How stable the dream environment is | Lower = more surreal distortions |
| **PERCEPTION** | Your current mode of sensory experience | Changes to DISTORTED, TEMPORAL FRACTURE, MULTIVERSAL AWARENESS, etc. |
| **DREAM TIME** | Non-linear temporal awareness | Displays impossible clock readings |

### Interaction System

**ChromaShift features a revolutionary dual control system:**

#### 🎯 Structured Control (Speech Bubbles)
- **360° Panoramic Exploration**: Drag to look around the surreal environment
- **Five Choice Bubbles**: 4 free exploration choices + 1 optional mission choice
- **Curated Outcomes**: Carefully crafted surreal scenarios
- **Guided Experience**: Perfect for first-time dreamers

#### 🌌 Generative Control (Command Interface)
- **Location Shifting**: Type any destination to instantly manifest there
- **Action Manifestation**: Type any action to reshape reality
- **Unlimited Freedom**: AI-interpreted surrealist responses
- **Total Agency**: No restrictions, no wrong inputs

#### 🔄 Hybrid Approach
- **Mix Both Systems**: Use bubbles for guidance, commands for creativity
- **Chromatist Powers**: As a lucid dreamer, you can control reality through language
- **Emergent Narrative**: Create your own story through exploration

#### Universal Features
- **Reality Blinks**: Periodic flickers that snap you between dream states
- **Eye Blink Mechanism**: Simulates the dreamer's consciousness blinking
- **Subconscious Whispers**: Cryptic messages from your deeper mind
- **Dream State Tracking**: Lucidity, coherence, and perception evolve with your choices

### **SUPERMARKET AISLE 7 [LIQUEFACTION ZONE]**

You wake in a sterile, brightly-lit supermarket aisle. But immediately, the surrealism overwhelms:

- **Flickering Neon**: Signs alternate between "FRESH" and "FLESH"
- **Impossible Physics**: Gravity and logic are completely broken

#### Initial Four Choices:

1. **Touch the liquid floor** → Experience tactile void and mercury contact
2. **Stare at the blinking mascot** → Commune with an entity from advertising hell
3. **Lick the melting clock radio** → Consume time itself and fracture temporal perception
4. **Walk through the meat cooler** → Discover a cathedral of alternate selves

Each choice leads to **completely different realities** with new surreal outcomes and four fresh choices, creating an infinite branching dreamscape.

## 🛠️ DEVELOPER NOTES

### Customization Guide

#### Adding New Choices
Edit `chromashift.js` → `initializeChoiceOutcomes()` method:

choice5: {
    title: 'YOUR SCENE TITLE',
    description: 'Elaborate surreal description...',
    wtfMoment: 'Brief anomaly description',
    statsChange: { lucidity: +10, realityCoherence: -5 },
    newChoices: [
        'Choice A',
        'Choice B', 
        'Choice C',
        'Choice D'
    ]
}

#### Changing Visual Style
Edit `chromashift.css` → `:root` variables:

--dream-gold: #FFD700;        /* Primary highlight color */
--neon-pink: #FF10F0;         /* Anomaly indicator */
--electric-cyan: #00FFFF;     /* Reality coherence */
--brightness-boost: 1.4;      /* Overall brightness */

#### Adding New Panoramas
1. Place image in `imgs/` directory
2. Update `currentScene.panoramaUrl` in `chromashift.js`
3. Supported formats: PNG, JPG (2048x1024 recommended)
