# 🎮 ChromaShift Player Features - Quick Start Guide

## 🚀 How to Use All New Features

### 📊 Collective Playtime Tracking
- **Automatic**: Playtime is tracked automatically as you play
- **View Stats**: Check the top-right stats panel for current totals
- **Global Display**: See how long ALL players have played together

### 🔄 Key Reset System  
- **Automatic**: Game resets automatically after every key collection
- **Fair Play**: No more advantages from previous runs
- **Notifications**: Reset confirmations show your stats

### 📺 Bottom Left TV (Narrative Viewer)
- **Click TV Icon**: Expand to see recent narratives
- **View Full Text**: Click any narrative for complete version
- **Keyboard Shortcut**: Press `Ctrl+T` to toggle
- **Manage History**: Use control buttons to clear or manage

### 🎤 Voice Input System
- **Click Voice Button**: Bottom-right microphone icon
- **Keyboard Shortcut**: Press `Ctrl+V` to toggle
- **Speak Actions**: Say your choices instead of typing
- **Visual Feedback**: Button glows when listening

### 🎵 Custom Radio Stations
- **Open Manager**: Use game interface to create stations
- **Upload Music**: Drag & drop or select audio files
- **Name & Describe**: Give your station personality
- **Multiple Genres**: Ambient, Electronic, Lo-Fi, Vaporwave, etc.
- **Play Controls**: Shuffle, repeat, volume, crossfade

### 📊 Player Stats Panel
- **Auto-Appears**: Shows in top-right by default
- **Toggle View**: Press `Ctrl+S` to show/hide
- **Real-Time**: Updates every second
- **Export Data**: Download your stats and stations

## 🎯 Feature Summary

| Feature | How to Access | Keyboard Shortcut | Purpose |

| Collective Playtime | Top-right stats panel | Auto-display | See community playtime |
